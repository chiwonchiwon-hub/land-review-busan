# 국·공유지 개발 검토

캠코(한국자산관리공사) 국유재산 담당자가, **국가·지자체 소유 토지를 찾고 → 청사·공공주택을 지을 수 있는지, 얼마나 지을 수 있는지 → 건물 모양과 사업비**까지 웹 화면 하나에서 검토하는 도구입니다. 검토 지역은 **부산광역시 전체(16개 구·군)** 입니다. 3D 건물은 대지 모양에 맞춘 7가지 안(대지 순응형, 판상형, 저층부+타워, ㄱ자, ㄷ자, 계단식, 병렬 2동)을 점수로 추천하고, 층수·층고·이격·건축면적 사용률 슬라이더로 바로 바꿔 볼 수 있습니다. 3D 지도는 마우스 오른쪽 버튼 드래그로 돌립니다.

기획은 [PRD.md](PRD.md), 단계별 개발 기록과 검증 결과는 [PLAN.md](PLAN.md)에 있습니다.

## 쓰는 법

0. 왼쪽 위 **말로 찾기** 창에 "해운대 좌동 청사 지을 국·공유지 300㎡ 이상"처럼 입력하면 조건을 알아듣고 바로 검색해요. 이어서 "학교용지도 포함해서 다시"처럼 조건을 고칠 수 있어요. 규칙 기반이라 외부 AI 키가 필요 없고, 못 알아들은 부분은 지어내지 않고 되물어요.
1. 왼쪽에서 **용도**(청사 / 공공주택 / 기타), 지역(수영구 동), 소유 구분(국유·시유·구유), 최소 면적, 제외할 지목을 고르고 **국·공유지 찾기**를 누릅니다.
2. 조건에 맞는 땅이 **일단의 토지**(붙어 있는 필지 묶음)로 지도와 목록에 나옵니다. 고른 용도로 법령상 지을 수 없는 용도지역의 땅은 목록에서 빠집니다.
3. 땅을 고르면 오른쪽에 리포트가 나옵니다: **검토 요약 → 위치·소유 → 규제·건폐율·용적률 → 용도 적합 여부 → 3D 건물 디자인 → 토지 가격·사업비**.
4. 지도 왼쪽 위의 **2D / 3D** 버튼으로 시점을 바꿉니다. **리포트 넓게 보기**를 누르면 검색 패널이 접힙니다.
5. 건물 디자인은 **3D 파일(GLB)** 로 내려받아 Blender·SketchUp·Rhino에서 이어서 다듬을 수 있습니다.

층고·대지경계 이격·건물 형태·㎡당 공사비·기타 비용 비율은 **가정값**이며 화면에서 고칠 수 있습니다.

## 실행하기 (Windows)

필요한 것: Node.js 20 이상, VWorld API 키 ([vworld.kr](https://www.vworld.kr)에서 발급).

```bash
npm.cmd install
```

프로젝트 폴더의 `.env` 파일에 키를 넣습니다. **이 파일은 `.gitignore`에 등록되어 있어 GitHub에 올라가지 않습니다.**

```
VWORLD_KEY=발급받은_키
# VWorld에 등록한 사이트 주소가 localhost가 아니면 그 주소를 적습니다 (기본값 localhost)
# VWORLD_DOMAIN=example.com
```

```bash
npm.cmd run dev
```

브라우저에서 http://localhost:3000 을 엽니다. (PowerShell에서 `npm run dev`가 "스크립트를 실행할 수 없습니다"로 막히면 `npm.cmd`를 쓰세요.)

운영용으로 실행하려면:

```bash
npm.cmd run build
npx.cmd next start
```

부산 전체 자료(필지·소유·용도지역·맞닿은 필지, 약 200MB)는 **처음 한 번** `node --env-file=.env scripts/build-busan-data.mjs`로 내려받아 `.cache/vworld/`에 저장합니다 (약 10분, 끊겨도 이어서 진행). 이후 검색은 저장된 자료만 써서 2~3초 걸립니다. 배포 환경에서는 `DATA_BASE_URL`(Vercel Blob 주소)에서 같은 자료를 gzip으로 받아 씁니다 (`scripts/upload-data.mjs`로 올림).

## 알아 둘 한계

- 법령·조례 표는 **부산 도시계획 조례의 용도지역 17종과 자연환경보전지역**을 반영했습니다. 관리·농림지역과 개발제한구역에 걸친 땅은 판정하지 않고 추천에서 뺍니다. 부산 밖으로 넓히려면 해당 지자체 조례를 확인해 `zoning-rules.ts`·`use-rules.ts`에 넣어야 합니다.
- 정비구역·지구단위계획·경관·고도지구, 방화지구 완화 등 **조건부·별도 규정은 계산에 넣지 않고 "확인 필요"로 알립니다.**
- 3D 건물은 단순한 직육면체 덩어리의 **배치 검토용 모형**입니다. 일조·사선 제한, 건축선, 주차장·조경 면적, 건축 설계 도면은 아닙니다.
- 사업비는 연면적에 단가를 곱한 단순 계산입니다. 지하층·토목·설계·금융비용·세금과 수익(분양·임대) 분석은 포함하지 않습니다.
- 건폐율·용적률 계산이 **담당자의 직접 검산과 일치하는지**는 아직 확인되지 않았습니다. [검산용_샘플10곳.md](검산용_샘플10곳.md)로 확인해 주세요.

## 유지보수

- **조례가 개정되면**: 부산시 도시계획 조례 제49조·제50조의 값이 바뀌었는지 보고 `lib/zoning-rules.ts`의 표와 `ORDINANCE.effective`·`checkedOn`을 고칩니다. 별표(건축 가능 용도)가 바뀌면 `lib/use-rules.ts`를 고칩니다.
- **공시지가가 새로 공시되면**: 저장된 `.cache/`를 지우면 새 자료로 다시 받습니다.
- **API 키는** 서버 쪽 코드에서만 읽습니다 (`lib/vworld.ts`). 브라우저로 보내지 않으며, 빌드 결과물에 키가 들어가지 않는 것을 확인했습니다. `.env`에는 이 앱에 필요 없는 다른 서비스의 토큰이 있다면 지우는 것이 안전합니다.
